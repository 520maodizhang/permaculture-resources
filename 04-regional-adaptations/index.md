# 区域适应

朴门原则是通用的，但**具体做法因地区而异**。

## 中国气候带

| 区域 | 气候特征 | 设计重点 |
|------|----------|----------|
| 华南 | 热带/亚热带 | 多层食物森林、雨水管理、耐热品种 |
| 华东 | 亚热带湿润 | 水稻整合、池塘系统、梅雨排水 |
| 华北 | 温带季风 | 冬季保温、温室、集雨抗旱 |
| 西北 | 干旱/半干旱 | swale集水、防风林、耐旱品种 |
| 西南 | 高原/山地 | 梯田、微气候利用、耐寒 |
| 东北 | 寒温带 | 温室延长季、储藏、耐寒品种 |

## 关键适应策略

### 水管理
- 南方：排水为主，防洪防涝
- 北方：集水为主，抗旱保水

### 建筑
- 南方：通风散热、遮阴防潮
- 北方：保温集热、密封防寒

### 植物选择
- 参考当地传统农业品种
- 引入适应的同纬度品种
- 保留本地野生可食用植物
