# 朴门三大伦理

> 伦理是朴门的道德基石。所有设计决策都必须通过伦理检验。
> 来源：Mollison 1981 PDC + Designers' Manual (pp.34-35) + permacultureprinciples.org

## 为什么伦理优先？

Mollison 反复强调：朴门不是技术集合，而是**伦理设计系统**。技术（swale、香蕉圈、食物森林）只是伦理和原则的产物。

> "朴门的根基是伦理和原则。正是通过理解这些，人们才能获得朴门全貌——而不是通过看那些从'朴门思考'中衍生出来的技术和策略。"
> — permacultureprinciples.org

伦理的作用是**约束设计决策的边界**——在"能做什么"之前先问"该做什么"。

## 三大伦理

### 1. 照顾地球（Care for the Earth）

> 所有生命系统都有内在价值，不依赖于对人类的用途。

**含义**：
- 土壤、森林、水、大气、所有生物都是设计必须考虑的"客户"
- 人类是地球的一部分，不是地球的主人
- 设计应增加而非减少生态系统健康
- 保留 wilderness（Zone 5）——不干预的自然区域

**实践含义**：
- 建设前先评估对土壤、水、生态的影响
- 优先使用可再生材料
- 设计应让生态系统更丰富、更稳定、更有韧性
- 不将废物排入自然系统

### 2. 照顾人类（Care for People）

> 满足人类对食物、住所、能源、社区、有意义工作的需求。

**含义**：
- 设计服务于人，但不以牺牲地球为代价
- 社区自给自足优于依赖远程系统
- 每个人都有能力影响自己的生活环境
- 公平获取资源

**实践含义**：
- 食物、水、能源系统应尽可能本地化
- 设计应考虑所有使用者的需求（包括老幼残障）
- 社区协作优于个人孤立
- 知识共享（如本仓库）

### 3. 公平分享 / 设限消费（Fair Share / Setting Limits）

> 设置消费上限，分享 surplus（剩余）。

**含义**：
- 地球资源有限，无限增长不可能
- 满足需求后，剩余应分享而非囤积
- 重新分配财富和资源
- 控制人口和消费

**实践含义**：
- 优先使用本地、可再生资源
- 减少能源和物质消费
- 分享知识、种子、收成、技能
- 设计系统应产生"剩余"而非"废物"——一个系统的输出是另一个系统的输入

## 伦理的层次关系

```
                    ┌─────────────────┐
                    │  照顾地球        │
                    │  (Earth Care)   │  ← 基础：没有健康的地球，一切无从谈起
                    └────────┬────────┘
                             │
                    ┌────────┴────────┐
                    │  照顾人类        │  ← 在地球健康的框架内满足人的需求
                    │  (People Care)  │
                    └────────┬────────┘
                             │
                    ┌────────┴────────┐
                    │  公平分享        │  ← 前两者满足后，限制消费，分享剩余
                    │  (Fair Share)   │
                    └─────────────────┘
```

注意层次关系：**地球优先于人类，人类优先于个人消费**。这不是说人不重要，而是说人依赖地球——地球垮了，人也活不了。

## Mollison 的态度原则

除了三大伦理，Mollison 还提出了一系列**态度原则**（attitudinal principles），这些在 Holmgren 的 12 原则中被整合，但 Mollison 原始版本中是独立的：

- **问题即资源**：每个"问题"都包含着解决方案的种子。杂草太旺？说明土壤有某种营养被释放。换一种利用方式，杂草变成绿肥。
- **做最少功**：系统自行运转越多，人为干预越少越好。"你不一定要做所有的工作。你可以让系统做。"
- **从最小系统开始**：先在小范围成功，再扩展。
- **出错是反馈**：设计失败不是失败，是信息。
- **生物资源优于化石资源**：用生物方案替代机械/化学方案。
- **最大化边缘**：边缘（ecotone）是生态最丰富的地方——森林与草地的交界、水与陆的交界。

> **交叉引用**：态度原则的完整列表见 [设计原则](03-principles.md)。Mollison 在 1981 PDC 中对这些原则的阐述见 [downloads/permaculture-pamphlets/1981-mollison-pdc-1.md](../downloads/permaculture-pamphlets/1981-mollison-pdc-1.md)

## 伦理与设计决策

一个朴门设计是否"朴门"，不取决于它用了什么技术，而取决于它是否遵循三大伦理。检验方式：

| 问题 | 伦理 |
|------|------|
| 这个设计是否增加或减少了生态系统健康？ | 地球 |
| 这个设计是否减少了生物多样性？ | 地球 |
| 这个设计是否满足了人的真实需求？ | 人类 |
| 这个设计是否依赖不可持续的远程输入？ | 人类 + 公平分享 |
| 这个设计产生的"废物"能否成为另一个系统的输入？ | 公平分享 |
| 这个设计是否鼓励囤积而非分享？ | 公平分享 |
