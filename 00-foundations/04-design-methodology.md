# 朴门设计方法论

> 如何将伦理和原则转化为实际设计
> 来源：1981 PDC + Permaculture Design Step-by-Step Guide + 综合资料

## 概述

朴门设计不是"想种什么就种什么"。它有一套系统化的设计流程，核心是：**先理解场地，再理解需求，然后从大模式到小细节逐步设计**。

---

## SADIMET 设计流程

SADIMET 是朴门常用的设计流程缩写：

```
S - Survey       调查：收集场地数据
A - Analysis     分析：理解数据含义
D - Design       设计：制定方案
I - Implementation 实施：执行方案
M - Maintenance  维护：管理系统
E - Evaluation   评估：反思与调整
T - Tweaking     微调：持续优化
```

这是一个**循环**，不是一次性流程——评估后回到调查，持续迭代。

## 核心设计工具

### 1. 扇区分析（Sector Analysis）

**目的**：识别穿过场地的所有"能量流"——包括想要的和不想要的。

**能量来源**：
| 扇区 | 想要的 | 不想要的 |
|------|--------|----------|
| 太阳 | 冬季阳光（温室、种植区） | 夏季暴晒（需遮荫） |
| 风 | 夏季微风（通风降温） | 冬季寒风、强风暴 |
| 水 | 雨水径流（收集利用） | 洪水、侵蚀 |
| 火 | — | 野火（需防火带） |
| 野生动物 | 授粉者、益虫 | 鹿、野猪（吃作物） |
| 人流 | 访客路径 | 偷盗 |
| 视线 | 美景 | 不雅观之物 |

**设计响应**：在能量来源方向放置能利用或阻挡该能量的元素。例如：冬季风方向种常绿防风林，夏季太阳方向留开放或种落叶树（冬透光、夏遮荫）。

### 2. 分区规划（Zoning）

**目的**：按使用频率和需要管理的强度，将场地划分为同心圆区域。

| 区域 | 含义 | 典型内容 | 访问频率 |
|------|------|----------|----------|
| Zone 0 | 住所 | 房屋、室内 | 每天多次 |
| Zone 1 | 密集管理 | 菜园、香草、鸡舍、温室 | 每天 |
| Zone 2 | 半密集 | 果树、浆果、主要作物、堆肥 | 每周 |
| Zone 3 | 农场尺度 | 大田作物、牧场、主林、大水坝 | 每月 |
| Zone 4 | 半野生 | 林地、放牧、采集、燃料 | 季节性 |
| Zone 5 | 野生 | 不干预的自然区域 | 观察 only |

**核心原则**：需要最多关注的元素放在最近的地方。每天要摘的菜放在厨房门口，一年去一次的林地放在最远处。

> **交叉引用**：分区详细设计见 [02-design-elements/01-zoning.md](../02-design-elements/01-zoning.md)

### 3. 需求与产出分析（Needs & Outputs Analysis）

**目的**：为每个设计元素列出它的需求（needs）和产出（outputs），然后匹配——让一个元素的产出满足另一个元素的需求。

**示例**：
| 元素 | 需求 | 产出 |
|------|------|------|
| 鸡 | 食物、水、庇护、沙浴 | 蛋、肉、粪、除草、翻土、报警 |
| 果树 | 水、阳光、授粉、修剪 | 水果、花蜜、落叶（堆肥）、遮荫 |
| 蜜蜂 | 花蜜、水、庇护 | 授粉、蜂蜜、蜂蜡、蜂胶 |
| 堆肥 | 有机物、水、空气 | 腐殖质（肥料）、热量 |

**设计**：鸡舍靠近果树（鸡吃落果减少病虫害，粪肥树）；蜂箱靠近果树（授粉）；堆肥靠近菜园（方便投料和取用）。

### 4. 演替设计（Succession Design）

**目的**：利用自然演替——生态系统随时间变化的过程——作为设计工具。

**演替序列**：
```
裸地 → 先锋植物（固氮、快速生长）→ 灌木 → 小乔木 → 森林
  0-1年        1-5年              5-15年   15-50年   50年+
```

**设计策略**：
- 第 1 年：种先锋物种（如绿豆、荞麦、固氮树苗）改良土壤
- 第 2-5 年：种灌木和浆果（已开始有产出）
- 第 5-15 年：种果树（先锋树可砍作覆盖物或保留）
- 第 15-50 年：食物森林成熟，多层产出

### 5. 坡度与等高线设计（Contour Design）

**目的**：利用地形管理水流动。

**关键概念**：
- **等高线（Contour）**：相同海拔的连线
- **Swale**：沿等高线挖的浅沟，截留雨水使其渗入土壤
- **Keyline**：Yeomans 发展的地形分析系统，识别主要山脊和山谷
- **水应该慢下来、散开来、渗下去**——而非快速流走

## 设计流程详解

### 第一步：调查（Survey）— 至少一年

**场地数据收集**：
- 气候：温度范围、降雨分布、极端天气、无霜期、日照时数
- 地形：坡度、坡向、等高线、海拔
- 土壤：类型、pH、有机质、排水、深度
- 水：现有水源、径流路径、地下水位、水质
- 生物：现有植被、野生动物、病虫害
- 人文：产权、法规、邻居、预算、时间
- 基础设施：建筑、道路、水电

**关键工具**：等高线地图、土壤检测、长期观察日记

### 第二步：分析（Analysis）

- 扇区分析图
- 分区规划图
- 需求产出矩阵
- 优势/劣势/机会/威胁

### 第三步：设计（Design）

- 从大模式到细节：先放水系统、通道、防风林，再放主要种植区，最后选具体品种
- 每个元素至少有 3 个产出
- 每个需求至少有 2 个来源
- 绘制最终设计图

### 第四步-七步：实施→维护→评估→微调

- 按演替时间线实施
- 持续观察和记录
- 每年评估调整
