# 社区与社会朴门

## 核心理念

朴门的第三伦理是**公平分享**（Fair Share），这要求我们不仅设计物质系统，也要设计社会系统。

## 应用层面

### 个人
- 技能交换：你教我堆肥，我教你修屋顶
- 时间银行：劳动时间记账交换
- 自我 sufficiency：减少对外部系统的依赖

### 社区
- 社区花园：共享土地和劳动
- 食物森林公园：公共可采摘的食物森林
- 工具图书馆：共享不常用的工具
- 种子库：保存和交换本地种子

### 经济
- 本地货币：促进本地循环
- CSA（社区支持农业）：消费者预付支持生产者
- 合作社：集体采购、集体销售

### 组织
- Sociocracy：基于同意的决策方法
- Holacracy：角色而非职位的组织结构
- 行动学习圈：边做边学的小组

## 设计原则的社会应用

| 朴门原则 | 社会应用 |
|----------|----------|
| 观察与互动 | 先了解社区需求再行动 |
| 边缘效应 | 不同群体交汇处最有活力 |
| 多样性 | 多元技能、多元文化 |
| 整合而非分离 | 连接不同社区资源 |
| 小而慢 | 从小项目开始积累信任 |
