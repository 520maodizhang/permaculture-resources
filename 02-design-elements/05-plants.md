# 植物

## 从单作到系统

传统农业是单一种植，朴门追求的是多层多种的功能性植物系统。

## 食物森林 (Food Forest)

模仿自然森林结构，但每一层都是可食用或有用的植物：

| 层次 | 高度 | 举例 |
|------|------|------|
| 冠层 | 10m+ | 坚果树（核桃、栗）、果树（苹果、梨） |
| 亚冠层 | 3-10m | 小果树（李、桃、柑橘） |
| 灌木层 | 1-3m | 浆果（蓝莓、覆盆子） |
| 草本层 | 0.5-1m | 香蕉、芦荟 |
| 地被层 | <0.5m | 草莓、甘薯 |
| 根层 | 地下 | 根菜类、球茎 |
| 藤本层 | 攀缘 | 葡萄、猕猴桃、豆类 |

## 伴生种植

| 组合 | 原理 |
|------|------|
| 三姐妹（玉米+豆+南瓜） | 玉米做支架，豆固氮，南瓜覆盖 |
| 番茄+罗勒 | 罗勒驱虫，提升风味 |
| 胡萝卜+洋葱 | 互相驱赶害虫 |

## 功能植物

| 功能 | 植物 |
|------|------|
| 固氮 | 三叶草、苜蓿、刺槐 |
| 动态积累 | 聚合草、蒲公英、荨麻 |
| 害虫驱避 | 万寿菊、薄荷、大蒜 |
| 天敌吸引 | 莳萝花、茴香、蓍草 |

## 植物组合 (Guild)

围绕一棵核心植物的一组功能互补的植物。苹果树组合：苹果树 + 球茎茴香（驱虫）+ 聚合草（提养分）+ 蒲公英（深根）+ 三叶草（固氮）。

## 选择原则

1. 适地适树：选择适合当地气候和土壤的品种
2. 多功能优先：每个植物至少两个功能
3. 演替思维：先种先锋植物改良土壤
4. 多样性：混种比单产更稳定
