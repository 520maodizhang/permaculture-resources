# 能源

## 核心理念

朴门的能源策略是：**先减少需求，再满足需求**。最好的能源是不需要用的能源。

## 能源层级（优先级从高到低）

1. **减少需求** — 保温、被动设计、行为习惯
2. **提高效率** — 高效设备、LED、节水器具
3. **可再生能源** — 太阳能、风能、水能、生物质
4. **化石能源** — 仅作备用

## 主要可再生能源

| 类型 | 适用场景 | 备注 |
|------|----------|------|
| 太阳能光热 | 热水、供暖 | 最经济的太阳能利用 |
| 太阳能光伏 | 电力 | 成本持续下降 |
| 风能 | 电力、抽水 | 需要稳定风资源 |
| 微水电 | 电力 | 有溪流即可，24h 发电 |
| 生物质 | 烹饪、供暖 | 薪柴、沼气、生物炭 |
| 地热 | 供暖/制冷 | 浅层地源热泵 |

## 生物质能

- **薪柴**：速生树种（柳、杨）矮林作业，3-5 年轮伐
- **沼气**：动物粪便+厨余 → 甲烷，同时产肥
- **生物炭**：低温热解，碳封存+土壤改良

## 能源规划

1. 审计现有能耗：电力、燃气、交通
2. 找到最大能耗项，优先削减
3. 评估可再生能源潜力（日照时数、风速、水流量）
4. 设计组合方案：太阳能光热 + 光伏 + 薪柴
5. 保留化石能源作为备用

## 关键原则

- **多样化**：不要只依赖一种能源
- **匹配用途**：光热用于热水，光伏用于电力
- **储能**：热质量储热、电池储电、水箱储热
- **系统整合**：温室供暖、灰水热回收、堆肥热
