# 扇区分析 (Sectoring)

## 定义

如果说分区管的是"东西放在哪"，扇区管的就是"外部能量从哪来、往哪走"。扇区分析是对穿过场地的**定向能量流**的规划。

## 主要扇区

| 扇区 | 来源 | 规划策略 |
|------|------|----------|
| **阳光** | 东→西移动 | 冬季阳光给住所和菜园，夏季用落叶树遮阴 |
| **风** | 主风向 | 防风林偏一侧，不要挡住良性微风 |
| **火灾** | 火灾来向 | 在火灾来向侧设防火带（绿带、水带、低燃植物） |
| **视线** | 道路/邻居 | 视线扇区种屏风植物，保护隐私 |
| **噪音** | 道路/工厂 | 噪音扇区种密植隔音带 |
| **水** | 径流方向 | 等高线种植截水，引导到蓄水点 |
| **野生动物** | 动物走廊 | 保留或引导，不阻断 |
| **污染** | 工业/喷雾 | 污染来向种缓冲带，敏感作物放另一侧 |

## 扇区分析步骤

1. **画场地平面图**，标出北向
2. **标出每个扇区的来源方向**：用箭头从边缘指向中心
3. **标注每个扇区的属性**：良性（需要引入）还是恶性（需要阻挡）
4. **设计应对策略**：
   - 恶性扇区 → 在入口处设缓冲（防风林、防火带、隔音带）
   - 良性扇区 → 在路径上设捕获点（集水、阳光房、风道）

## 分区 vs 扇区

| | 分区 (Zone) | 扇区 (Sector) |
|--|------------|--------------|
| 管什么 | 内部元素位置 | 外部能量走向 |
| 维度 | 同心距离 | 方向角度 |
| 依据 | 访问频率 | 能量来源方向 |
| 类比 | "冰箱在厨房" | "窗户朝南" |

两者**叠加使用**：先做扇区分析确定能量走向，再做分区规划安排元素位置。

## 实践案例

**山坡场地**：
- 住宅放在山腰偏南（阳光扇区 + 分区 Zone 0）
- 防风林种在西北角（冬季风扇区）
- 集水 swale 沿等高线（水扇区）
- 薪柴林在北侧远处（分区 Zone 4 + 视线屏风）
- 防火带在南侧下方（火灾扇区，火从下往上烧）
