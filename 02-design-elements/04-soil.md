# 土壤

## 核心理念

朴门不"耕"土壤，而是**建造**土壤。目标是将裸露的、贫瘠的地面转化为富含有机质、充满微生物生命的活土壤。

## 土壤建造方法

### 1. 堆肥 (Compost)
- 碳氮比 30:1 为最佳
- 分热堆肥（快速杀菌）和冷堆肥（慢但保留更多微生物）
- 放在分区 Zone 1，方便日常投放

### 2. 覆盖物 (Mulch)
- **最重要的单一实践**：永远不要让土壤裸露
- 材料：稻草、木屑、落叶、剪草、纸板
- 功能：保水、抑草、调节土温、分解后增加有机质

### 3. 绿肥 (Green Manure)
- 种覆盖作物然后翻入土壤
- 豆科固氮（三叶草、苜蓿、紫云英）
- 深根作物提土底层养分（黑麦、萝卜）

### 4. 纸板堆肥法 (Sheet Mulching)
- 又称"lasagna gardening"
- 纸板/报纸 → 堆肥 → 覆盖物 → 种植
- 不翻地，直接在草地上建新菜园

### 5. 动物整合
- 鸡拖拉机：鸡刨地+吃虫+施肥
- 猪翻地：深翻+施肥
- 蠕蚓：最高效的土壤建造者

## 土壤类型与改良

| 土壤类型 | 特点 | 改良策略 |
|----------|------|----------|
| 沙土 | 透水快、保水差 | 大量有机质+黏土矿物 |
| 黏土 | 保水好、透气差 | 有机质+粗沙+ gypsum |
| 壤土 | 理想质地 | 维持有机质输入 |
| 酸性土 | pH<6 | 加石灰、木灰 |
| 碱性土 | pH>7 | 加硫磺、松针、泥炭 |

## 土壤食物网

```
植物残体 → 真菌/细菌 → 原生动物 → 线虫 → 蚯蚓/甲虫
    ↑                                    ↓
    └──── 养分释放 ←────────────────────┘
```

健康的土壤有完整的食物网，养分在生物间循环，不需要外部化肥。

## 关键指标

- **有机质含量**：>5% 为优秀
- **pH**：6.0-7.0 适合大多数作物
- **保水性**：手握成团不滴水为宜
- **生物多样性**：一把土里有几条蚯蚓
