# 建筑

## 核心理念

朴门建筑追求的是：**用当地材料、适应当地气候、最低外部能源输入**。建筑不是孤立的物体，而是整个系统的一个要素。

## 被动太阳能设计

| 要素 | 冬季目标 | 夏季目标 |
|------|----------|----------|
| 朝向 | 长边朝南（北半球） | 同左 |
| 窗户 | 南面大窗采光吸热 | 屋檐遮阴 |
| 热质量 | 石/砖/水储热 | 夜间通风散热 |
| 保温 | 北面厚墙少窗 | 同左 |
| 通风 | 密封保温 | 穿堂风 |

## 自然建筑材料

| 材料 | 优点 | 缺点 |
|------|------|------|
| 夯土 | 保温好、就地取材 | 劳动密集 |
| 草捆 | 保温极好、便宜 | 防潮处理 |
| 木框架 | 快速、灵活 | 需要木材来源 |
| 土袋 | 简单、抗震 | 劳动密集 |
| 柱泥 | 便宜、塑形 | 需要干燥气候 |

## 其他建筑要素

- **温室**：附在住宅南侧，既是种植空间又是热缓冲
- **雨水收集**：屋顶是最大的集水面
- **灰水处理**：建筑排水设计
- **堆肥厕所**：节水+产肥
- **太阳能/风能**：屋顶安装

## 设计原则

1. 先考虑**不建**：能否改造现有建筑？
2. 小而美：面积够用就好，每平方米都要维护
3. 多功能：温室既是种植、供暖、生活空间
4. 可维修：自己能修的才是好建筑
