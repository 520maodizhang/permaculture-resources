# 设计要素

朴门设计不是凭空想象，而是对一组相互关联的**设计要素**进行系统性分析与整合。每个要素都不是孤立的，它们之间通过模式与连接形成整体系统。

## 要素总览

| 要素 | 核心问题 | 关键概念 |
|------|----------|----------|
| [分区规划](./01-zoning) | 东西放在哪？按访问频率安排 | Zone 0-5 |
| [扇区分析](./02-sectoring) | 外部能量如何进出？ | 风向、阳光、视线、火灾 |
| [水](./03-water) | 如何捕获、储存、分配？ | Swale、池塘、集雨 |
| [土壤](./04-soil) | 如何建造和维持？ | 堆肥、覆盖物、绿肥 |
| [植物](./05-plants) | 选什么、怎么组合？ | 食物森林、伴生、轮作 |
| [动物](./06-animals) | 动物如何融入系统？ | 鸡拖拉机、放牧轮换 |
| [建筑](./07-structures) | 建什么、用什么材料？ | 被动太阳能、自然建筑 |
| [能源](./08-energy) | 能从哪来？如何减少需求？ | 太阳能、风能、生物质 |
| [气候](./09-climate) | 我们在什么气候带？ | 热带、温带、干旱、寒带 |

## 设计要素之间的关系

```
          气候 ──→ 水 ──→ 土壤
            │        │       │
            ↓        ↓       ↓
          植物 ←── 动物 ←── 能源
            │        │       │
            └──→ 建筑 ←── 分区 ←── 扇区
```

每个要素的设计决策都会影响其他要素。好的设计是在所有要素之间找到**最优平衡点**，而不是单独优化某一个。

## 设计原则的体现

设计要素的应用遵循 Holmgren 的 12 条原则，特别是：

- **观察与互动**：在改变任何要素之前，先观察一个完整周期
- **整合而非分离**：让要素之间互相服务（鸡吃菜园害虫，鸡粪肥田）
- **每个要素多种功能**：池塘既是水源，也是防火储备，还是水生食物
- **能量高效规划**：分区和扇区就是能量效率的空间表达
