# 案例研究

## 经典案例

### 1. 赛壁丁顿农场 (Djanbung Gardens, Australia)
- 位置：澳大利亚新南威尔士
- 面积：5 公顷
- 设计者：Robyn Francis
- 特点：从退化牧场到成熟食物森林，20 年演替
- 教训：耐心是关键，系统需要时间成熟

### 2. 绿色之城农场 (Bullock's Permaculture Homestead, USA)
- 位置：美国华盛顿州 Orcas Island
- 面积：约 4 公顷
- 特点：温带食物森林、多样化产出
- 教训：多品种混种降低风险

### 3. Jordan 干旱谷项目 (Greening the Desert, Jordan)
- 位置：约旦死海谷地
- 面积：小型示范
- 设计者：Geoff Lawton
- 特点：在极端干旱中用 swale+覆盖物建绿洲
- 教训：水管理是干旱区的一切

## 中国案例

### 4. 安龙村生态家园 (四川)
- 特点：地震后重建，朴门原则指导村庄设计
- 要素：沼气、雨水收集、食物森林、社区合作

### 5. 小毛驴市民农园 (北京)
- 特点：CSA 模式，社区支持农业
- 要素：有机种植、会员制、教育推广

## 从案例中学到的

1. **每个场地都独特**：不能照搬，只能借鉴原则
2. **时间是最好的盟友**：系统需要 5-20 年成熟
3. **从最小开始**：先做好 Zone 0-1
4. **观察重于行动**：先看一年再动
5. **社区比技术重要**：没有社区支持，技术难持续
