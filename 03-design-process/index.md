# 设计流程

## 总流程

```
观察 → 分析 → 设计 → 实施 → 评估 → 调整
 ↑                                      │
 └────────────── 循环 ←─────────────────┘
```

## 阶段详解

### 1. 观察 (Observation)
- 至少观察一个完整年周期
- 记录：日照轨迹、风向、水流、野生生物、现有植被
- 不急于行动，先理解场地"想成为什么"

### 2. 分析 (Analysis)
- 分区分析：访问频率
- 扇区分析：能量走向
- 需求分析：你想要什么产出
- 资源清单：你有什么（水、土、材料、时间）

### 3. 设计 (Design)
- 画概念图：水系统、通道、分区
- 画详细图：每个分区内的具体布局
- 植物组合设计
- 时间表：先做什么后做什么

### 4. 实施 (Implementation)
- **从水和土壤开始**：先建基础设施
- 顺序：水 → 土 → 路径 → 围栏 → 植物 → 动物 → 建筑
- 小步快走：先做 Zone 0-1，再向外扩展

### 5. 评估与调整
- 每季度回顾：什么有效？什么没效？
- 系统在演替，设计也要跟着变
- 保持 Zone 5 的观察心态
